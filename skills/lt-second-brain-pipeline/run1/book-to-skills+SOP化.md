# book-to-skills + SOP 化（方法）

**观点**：把书/资料蒸馏成可复用 skill，再提炼为含 LLM+脚本的明确 SOP 严格执行，是知识落地的标准方法。

**为何重要**：框架/知识若不 SOP 化就无法稳定复用；"含 LLM 部分 + 明确脚本"把智能与确定性分离，省钱保一致。

**证据**：来源笔记：「应该还需要把它提炼成明确的 SOP……这里面就需要包含 LLM 负责的内容，也需要包含一些明确的一些脚本。」

**连接**：
- 是「第二大脑」的构建方法（本知识库已实践：thinking-truth → skill → 第二大脑管线 SOP）。
- 相关已有资料：《13｜Skills架构定位》、《课程生成 SKILL.md》、《Skill 设计技巧教程.pptx》。

**实践印证**：本笔记自身就是该方法产物——从《思考的真相》蒸馏 skill，再接成工作流 SOP。
