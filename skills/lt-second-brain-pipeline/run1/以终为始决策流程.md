# 以终为始决策流程（可复用 SOP）

**适用**：判断"某事务是否值得投入"时。

**步骤**：
1. 定义最终目标（如：一人创业）。
2. 列出当前在做的 / 想做的事务。
3. 对每件事判断：方向是否与最终目标一致？
4. 一致 → 投入（苦值得，方向红利）；不一致 → 放弃或降级（避免卖时间/体力的无效投入）。

**来源**：《最近所思所想》+ 李笑来六要素（决策 = 定义+分类+比较+因果的组合嵌套）。

**关联概念**：以终为始、一人创业。
