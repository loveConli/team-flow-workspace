# AI 外包筛选 / 总结（杠杆）

**观点**：将资料分析、信息筛选外包给 AI/Agent（如每日从 YouTube/B站主动筛选目标相关内容），可替代被动刷短视频，节省时间聚焦深度思考。

**为何重要**：信息海洋里人工筛选极耗时；AI 预处理是杠杆，把人从"刷消息找有用信息"中解放。

**证据**：来源笔记末段：写技能让 Agent 每日从 YT/B站筛选好内容，「这样子我们就没有必要去花很多时间去刷」。
