# 以终为始（决策原则）

**观点**：做事前先明确最终目标，再校验当前事务方向是否与之对齐；对齐则投入（苦值得），不对齐则放弃。

**为何重要**：迷茫与精力错配的根本解法是"目标锚定"而非"路径焦虑"。定义（目标）缺失 → 无法分类比较 → 无法决策，这正是"迷茫"的成因。

**证据**：
- 来源笔记《最近所思所想》：「先明确最终目标，再判断当前事务是否与目标方向一致，若不一致则无需投入过多时间精力。」
- 同构：企业架构材料中的"战略层/规划层/实施层"三层模型（规划层薄弱导致战略与执行脱节）。

**连接**：
- 是「一人创业」的决策判据（一人创业 = 这里"最终目标"的实例）。
- 指导「AI Coding 课是否值得吃辛苦」的一致性判断。
- 可落地为流程：见《以终为始决策流程》（05-Skill）。

**偏见提示**：本原则本身不回答"目标本身是否正确"，需配合反方调研（改进建议 1）。
