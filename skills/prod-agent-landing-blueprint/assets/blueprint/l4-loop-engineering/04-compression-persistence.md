## 压缩策略分级

| 级别 | 名称 | 触发条件 | 保留内容 | 丢弃内容 | 适用场景 |
|------|------|----------|----------|----------|----------|
| L1 | 工具结果清除 | 每轮对话后 | 工具结论 | 原始工具输出（大段日志/代码） | 日常对话，token 充裕 |
| L2 | 内容摘要 | 剩余 token ≤ 4000 | 用户意图、关键决策、结论 | 过程性对话、追问细节、尝试性代码 | 标准会话 |
| L3 | 高保真蒸馏 | 剩余 token ≤ 2000 | 架构决策、未解决 bug、实现细节、接口变更 | 过程性对话、已验证的假设、临时调试 | 长会话、复杂需求 |
| L4 | 完全重启 | 剩余 token ≤ 1000 或会话 > 2 小时 | 仅保留 status-tracker 机读块 + NOTES.md 摘要 | 几乎全部对话内容 | 超长会话、token 告急 |

## 高保真蒸馏内容标准

> 报告原文："高保真蒸馏：保留架构决策、未解决 bug、实现细节，丢弃过程性对话。"

**必须保留**（写入 NOTES.md 的 `distilled` 区块）:
1. **架构决策**: 本次会话中做出的架构选择、技术选型、设计模式变更
2. **未解决 bug**: 发现但未修复的问题、待调查的异常
3. **实现细节**: 关键算法、核心逻辑、复杂分支的处理方式
4. **接口变更**: API 签名变更、数据库 schema 变更、配置变更
5. **关键决策**: 影响后续 phase 的决策（如采用某种回滚策略、选择某种测试方案）
6. **阻塞原因**: 当前 BLOCKED / WAITING_USER 的原因和上下文

**可以丢弃**:
- 过程性对话（"让我想想..."、"试试这种方式..."）
- 已验证的假设（验证通过后无需保留验证过程）
- 临时调试代码（调试通过后丢弃）
- 重复的信息（之前会话已记录的内容）
- 工具输出的原始数据（保留结论即可）

## 压缩触发器配置

```yaml
# compression-config.yaml（骨架）
triggers:
  token_threshold: 2000        # 剩余 token ≤ 2000 触发 L3 高保真蒸馏
  time_threshold: 120          # 会话超过 120 分钟触发压缩
  turn_threshold: 20           # 超过 20 轮对话触发压缩
  
strategy:
  default: L2                  # 默认使用内容摘要
  emergency: L4                # token 告急时使用完全重启
  
output:
  notes_file: memory/NOTES.md  # 蒸馏后写入的位置
  format: markdown             # 格式
  max_lines_per_distill: 50    # 每次蒸馏最多写入 50 行
```

## 压缩与 Loop 原语的集成

| Loop 原语 | 压缩关联 | 说明 |
|-----------|----------|------|
| 指令（instruction） | 约束型上下文，永不压缩 | 写入 CLAUDE.md，跨会话永久 |
| 工具（tools） | 工具白名单，L1 清除原始输出 | 保留工具结论，丢弃原始输出 |
| 上下文（context） | L2-L3 压缩对象 | 信息型上下文，可压缩更新 |
| 记忆（memory） | L3 蒸馏结果写入 NOTES.md | Permission 策略拉回 |
| 终止（termination） | L4 完全重启前触发蒸馏 | max_turns / token 上限时 |
| 评估（evaluation） | 压缩后重新评估上下文质量 | 判断是否需要 WAITING_USER |

## 渐进式披露通过 Loop

> 报告原文："每次交互产出上下文指导下一步决策（文件大小/名称/时间戳作为信号）——不是一次性加载所有信息，而是每步产出指导下一步的上下文信号。"

**实现方式**:
1. 会话启动时仅加载轻量标识符（文件列表、状态机机读块）
2. 每步执行后更新 NOTES.md 的「下一步信号」
3. 下一步执行前读取 NOTES.md 的「下一步信号」→ 决定加载哪些详细上下文
4. 避免一次性加载全部文件 → 按需渐进披露

## 持久化与 L2 三仓库的集成

```
上下文压缩
  │
  ├─ 蒸馏结果 ──► NOTES.md ──► 项目记忆仓库（feature 分支）
  │                              （Session 级持久化）
  │
  ├─ 稳定知识 ──► 长期 wiki 仓库（master 分支）
  │                （跨需求持久化，结项审视后）
  │
  └─ 归档 ───────► 项目记忆仓库 archive/（一次性材料）
                   （可清理）
```
