# Cheatsheet — 《思考的真相》速查与判断

> 决策规则为主：遇到 X，就做 Y，因为 Z。贴在手边用。

## 一、复杂问题决策树
```
遇到复杂问题
├─ 先问：概念定义清楚了吗？（必要且无歧义？）
│   └─ 否 → 先定义（概念=描述），别往下走
├─ 再问：要枚举的选项/原因分类合理且完整吗？（不重合+等于全部）
│   └─ 否 → 重做分类（MECE）
├─ 再问：能比较吗？（同一范畴、同一属性？）
│   └─ 否 → 不可比，停下或换属性
├─ 再问：这是因果还是只是相关/时序？
│   └─ 用四问：真因？唯一因？还有哪些因？最重要因？
└─ 最后：决策 + 画流程图落地（顺序/循环/判断分支，能并联都并联）
```

## 二、判断原则（Tells & Smells）
- 看到"因为A发生在B前，所以A导致B" → **闻到了时序当因果**，用四问拆。
- 看到"这两件事一起出现" → 先查是否**相关非因果**（同因第三方）。
- 争论不下且各说各话 → 多半是**定义不同**，回去对齐 `概念=描述`。
- 选项清单总觉得"少了点什么" → **分类不完整**，补到"等于全部"。
- 决策靠"我觉得" → 逼出**客观依据**并赋权重打分。
- 做事手忙脚乱/总漏步 → 画**流程图**，补漏步骤，能并联都并联。

## 三、因果四问卷（随身带）
1. A 真的是 B 的原因吗？
2. A 是 B 的唯一原因吗？
3. 还有哪些原因？
4. 最重要的原因到底是什么？

## 四、加权比较模板
| 依据 | 权重 | 选项A | 选项B | 选项C |
|------|------|-------|-------|-------|
| 依据1 | 40% |       |       |       |
| 依据2 | 30% |       |       |       |
| 依据3 | 20% |       |       |       |
| 依据4 | 10% |       |       |       |
| **总分** | 100% |       |       |       |
规则：依据尽量客观、可量化；权重合计=100%。

## 五、流程统筹两条铁律
- **漏步骤 = 灾难**（出门忘钥匙、开车漏检胎）。大事必先画流程图。
- **能并联的都并联** = 省时的唯一核心（华罗庚泡茶：16 分靠并联）。
