# ch06 — 1.5 决策

## 核心定义
- "生活中我们做的每一个决策，无论重要与否，背后的思考其实都是**定义、分类、比较、因果这四个要素的组合应用**。"
- 在 1.6 的 What/Why/How 对应表中，**"为何"(Why) 对应"决策"**——决策是四要素组合后的自然产出/最终动作。

## 关键原则
- **要素组合原则**：每个决策都是定义+分类+比较+因果的组合应用。
- **先后原则（微妙但存在）**：定义 → 分类 → 比较 → 因果。
- **嵌套使用原则**："到最后都是组合嵌套使用"——因果分析完再分类、再比较找最重要原因，多轮循环。

## 操作步骤（决策的四要素嵌套）
1. **先定义清楚**：明确概念与标准（定义兴趣/长处、健康饮食标准）。
2. **再合理分类**：划为互不重合且完整的类别（职业领域、食物健康与否）。
3. **然后比较**：同一范畴同一属性下比较（哪职业更符合需求、食物是否符合标准）。
4. **接着因果分析**：思考原因结果（职业能否带来满足感/足够收入、食物对身体的影响）。
5. **组合嵌套**：非单线，而是多轮循环，以决策为目标。
- 简化框架："凡事从这四个要素出发……所有复杂的问题，其实都是由这些简单的要素组合或叠加构成的，逐一突破即可。"

## 反模式
- **跳过基础要素直接拍脑袋**：多数人决策前不做定义/分类/比较/因果拆解。
- **分类不合理导致偏差**：如生产四要素重合，以此决策无效。
- **定义不清就比较/决策**：如把"火"当炎症直接决策必误。
- **因果误判用作决策依据**：把相关当因果，忽略真因。

## 具象例子
- **职业选择**：定义兴趣长处 → 分类职业领域（科学/艺术/教育）→ 比较符合度 → 因果（满足感、收入）→ 明智选择。
- **饮食习惯**：定义健康标准（低热量高营养）→ 分类食物（健康/不健康）→ 比较挑选 → 因果（对身体的影响）。
- **买特斯拉代步车**：先油车/电车分类比较，再电车品牌比较，后据因果做决定（比较与因果嵌套）。
- **买特斯拉股票（定义差异致决策差异）**："特斯拉从一开始就是一家机器人制造公司，而不是大多数人以为的汽车制造公司……这就是由于**定义不同，进而理解不同，而后分类和比较都不同，决策自然也不同**。"另引李书福定义汽车="两张沙发配四个轮子加一个铁壳"，说明同一事物不同定义致决策差异。（书中标注：该投资仅作实例，不构成投资建议。）

## 与其他要素的关系
- **线性先后**：定义→分类→比较→因果，决策是出口。
- **嵌套循环**：因果后可能回到分类/比较，以决策为目标多轮嵌套。
- **差异定义致决策差异**：定义=决策链第一环（特斯拉例）。
