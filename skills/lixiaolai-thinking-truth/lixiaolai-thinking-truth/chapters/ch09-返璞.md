# ch09 — 3 返璞：类比 / 发展 / 简单 / 升级

> 返璞章在原书中"介绍了一个高级的思考方式叫做类比，去研究了发展论，返璞归真的去研究简单的东西，最后讲到了思维升级的方法"。本章依据书名、主题词与"7句话"等公开材料做**框架级还原**；原书逐节正文未完整包含在可用文本中，凡细节请以原书核对。

## 3.1 类比
- 由"比较"中的"约等于"发展出的高级思考方式："约等于对应一种思考模式，叫**类比**——它非常重要。"
- 用法：在两个不同范畴间，就某一属性做"约等于"映射，借已知理解未知（如"时间就是金钱"是以金钱的属性类比时间）。
- 边界：类比是启发而非证明；类比成立的前提仍是"同一属性"上的近似，不可越界当因果。

## 3.2 发展
- 两类未来观（"7句话"第6句）：
  - **设计论者**：不能接受意外和不可想象，本质上需要一个确定的未来——"当然这从来都只能是一厢情愿"。
  - **发展论者**：笃行的是"发展的存在与发展的力量"，而不是哪个确定的发展结果——**未来是不确定的，也应该是不确定的**。
- 实践含义：用发展论者视角做长期决策，接受不确定性，押注"发展与力量"而非某个既定结局。

## 3.3 简单
- "返璞归真的去研究简单的东西"——回归基础六要素，不堆砌复杂。
- 与全书基调一致：思考"说它简单吧，小学毕业前后就应该且能够掌握"；简单可习得、可复用，才是真功夫。

## 3.4 升级
- "讲到了我们的思维升级的方法"——升级不是学更多概念，而是让三张表（概念表/关系表/流程表）更准、更全、更活（见 ch10）。
- 方法落点：反复迭代四要素 → CRUD 操作 → 长时间积累 → 认知/判断/行动升级。

## 与其他章的关系
- 类比承接"比较"的"约等于"；发展承接"因果/未知"的不确定性；简单回归基础六要素；升级指向"三张表"这一操作系统隐喻。
