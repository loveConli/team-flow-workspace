# ch10 — 三张表（大脑操作系统）与全书应用

## 三张表：大脑的操作系统
李笑来收束全书的核心隐喻："我们在脑子里不管你有意无意，我们的脑子里都有三张表。一张表叫做**概念表**，而另外一张表叫**关系表**，还有一张表叫做**流程表**，这些构成我们的大脑的操作系统。"
- **概念表** ← 定义（概念=描述，CRUD 维护）
- **关系表** ← 分类、比较、因果、关系（从属/与或非/并列递进转折/相关非因果）
- **流程表** ← 流程（顺序/循环/判断与分支）

闭环（"7句话"第7句）：从定义、分类、比较、因果这四个极简单要素构成的思考框架开始，**不断迭代** → 概念表、关系表、流程表逐步积累 → 由四个简单操作构成的 **CRUD**（新建/读取/更新/删除）→ 经长时间反复，形成各种**认知、判断、行动** → 最终通过**时间**这个发展的唯一路径 → 逐步形成所谓的**命运**。"起初的时候，谁能想象？"

## 7句话（读者整理，原书金句级）
1. 事实上，所有复杂的问题，都是由定义、分类、比较、因果，这些简单的要素组合或者叠加构成的，逐一突破即可。
2. 做事的本质，做什么都一样，无非是对流程的规划和管理；把事做好或者提高效率，无非就是对流程的优化而已，无他。
3. 所谓的智能，核心只不过是判断；而判断的核心，无非是恰当的比较和合理的分类，前提是必要且毫无歧义的定义。
4. 我们所在的世界不是一维因果世界，也不是二维因果网络世界，而是由时间串起的无数因果网络而构成的三维因果系统世界。
5. 不要误以为统计概率是理科生才需要的东西，无论是历史学、经济学、政治学，还是商业管理、公共决策，都一样，但凡想理解大量且复杂的事实，且需要深入分析，都需要扎实的统计概率基础。一定要认真学习统计概率，勤于实践。没学过、没学会、没学好，很吃亏——哪怕去买股票都会吃大亏，还根本不知道自己亏在哪里。
6. 设计论者不能接受意外和不可想象，他们本质上需要一个确定的未来——当然这从来都只能是一厢情愿。发展论者笃行的是发展的存在与发展的力量，而不是哪个确定的发展结果——未来是不确定的，也应该是不确定的。
7. 从定义、分类、比较、因果这四个极为简单的要素构成的思考框架开始，不断迭代……逐步形成所谓的命运。

## 看厚读书法（如何把薄书学透）
- 薄册子要"反复看""多看几遍""看厚"——用过往著作/课程/生活经历去填充。
- "你还要把它讲很多遍"——讲给家人听（"我怎么讲给我家孩子呢？我怎么讲给我老公呢？"），把它变成你的讲义。
- 检验真学没学到：脑中"概念表、关系表、流程表"是否真的发生了变化。

## 框架的应用（投资 / 学习 / 人生）
- **与财富**：李笑来称其财富（如《托福核心词汇21天突破》长期版税、《通往财富自由之路》稿酬、GAFATA/ANATM 及港交所 ETF 投资）均源自这套清晰简单的思考框架；关键是"定义不同 → 理解不同 → 分类比较不同 → 决策不同"。
- **与学习/自学**："思考其实是每个人受教育的素质基础，也是每个人自学的基础"；学校不教思考，故需自修。
- **与人生**：命运是四要素经时间迭代的产物；"用正确的方式去做正确的事情"（出自《把时间当做朋友》）——事错则越高效越倒霉，事对则效率稍低无妨。

## 统计概率基础
- 见"7句话"第5句：理解大量复杂事实、做深入分析与公共/商业决策都需扎实统计概率；它是驾驭"三维因果系统世界"与"未知"的工具。
