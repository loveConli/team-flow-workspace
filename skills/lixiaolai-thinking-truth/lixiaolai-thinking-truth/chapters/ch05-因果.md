# ch05 — 1.4 因果

## 核心定义
- 从时序与科学探究角度描述（原书未给"因果=…"式形式定义）：
  - "当一个原因产生一个结果的时候，总是原因在前，结果在后。"
  - "我们从小就被教育过，**时间上的先后顺序并不保证因果关系**。"
  - "因果关系的探究从来都不容易，甚至，因果分析几乎是科学的核心。"

## 关键原则
- **时间先后 ≠ 因果**。
- 因果分析极难，是科学核心；普通人常直接采纳专家成果，但生活中难免自己研究。
- 原因往往**不止一个**，需追查"最重要原因"，超越单一表面原因。

## 操作步骤（因果四问模板）★核心方法
> 1. A 真的是 B 的原因吗？
> 2. 如果 A 是 B 的原因，那么，A 是 B 的**唯一**原因吗？
> 3. 如果 A 不是 B 的唯一原因，那么**还有哪些原因**？
> 4. 如果 A 不是 B 的**最重要**原因，那么最重要的原因到底是什么？

- "这个提问流程虽然简单，却相当够用。日常生活里绝大多数因果分析，哪怕仅用这四个问题过一遍，就已经超越了绝大多数人的'思考'（或'不思考'）。"
- 配套流程图：开始 → A 真因 B？→（是）→ A 唯一因？→（否）→ 还有哪些因？→（针对最重要）→ 最重要因是什么？→ 结束。
- 找到种种原因后，也要对原因**分类**（内部/外部），再**比较**找最重要的那个——即与分类、比较嵌套。

## 反模式
- **混淆时序与因果**：以为"原因在前结果在后"即因果。
- **误将相关当因果**：典型反例"冰激凌销量↑ → 溺水人数↑"，二者同因于"天气热"，非因果；误认会忽略真因（见 ch08 相关非因果）。
- **只找单一原因 / 归因不足**：四问模板即针对"止步于单一表面原因""不找最重要原因"的纠正。
- **不思考**：多数人决策前根本不做因果拆解。

## 具象例子
- **科学方法例**：双盲实验、谁主张谁举证、回归分析、随机对照试验、蒙特卡洛模拟——用作确定因果的方法。
- **相关非因果反例**：冰激凌销量与溺水人数同因于天热。
- **日常研究局限**：普通人研究能力/生产资料有限，常囫囵吞枣采纳专家成果，但问题太多难免自己动手。

## 与其他要素的关系
- 顺序链条：**定义 → 分类 → 比较 → 因果**。
- 嵌套：因果分析完，对各种原因分类、比较，找最重要原因。
