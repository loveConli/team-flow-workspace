# ch10 — 三张表（大脑操作系统）与全书应用

## 三张表：大脑的操作系统（源自 3.4 升级，已逐字确认）
"无论是有意还是无意，我们的脑子里都有三张表：概念表、关系表、流程表……这三张表就构成了我们的操作系统……本质上来看都是对这三张表执行 CRUD 操作——新建、读取、更新和删除。而所谓升级，本质上不过是在不断 CRUD 而已。"
- **三表 ↔ 认知/判断/行动**：概念表 → 认知；关系表 → 判断；流程表 → 行动。
- **形成顺序**：概念表梳理好 → 关系表才清楚 → 流程表才最优；动作上先认知、后判断、再行动。
- **来源映射**：概念表 ← 定义/分类；关系表 ← 比较/与或非/类比/因果；流程表 ← 流程/决策。
- **升级机制**：以定义、分类、比较、因果四要素为起点框架，长期迭代 CRUD。

## 判断标准（学习效果自检）
"真正有意义的学习、思考和实践，都会引发这三张表的变化、积累或更新。反过来……这三张表竟然没有发生任何变化，那其实等于没学、没思考、没实践——钱白花、时间白费。"
→ 任何书/课/讨论后，问自己：我的概念表、关系表、流程表变了吗？没变 = 无效投入。

## 命运公式
"这三张表刚开始几乎空空如也，从定义、分类、比较、因果这四个极为简单的要素构成的思考框架开始，不断迭代……经过长时间的反复，形成各种认知、判断、行动，最终通过时间这个发展的唯一路径，逐步形成所谓的命运。起初的时候，谁能想象？"

## 7句话（读者整理，原书金句级）
1. 事实上，所有复杂的问题，都是由定义、分类、比较、因果，这些简单的要素组合或者叠加构成的，逐一突破即可。
2. 做事的本质，做什么都一样，无非是对流程的规划和管理；把事做好或者提高效率，无非就是对流程的优化而已，无他。
3. 所谓的智能，核心只不过是判断；而判断的核心，无非是恰当的比较和合理的分类，前提是必要且毫无歧义的定义。
4. 我们所在的世界不是一维因果世界，也不是二维因果网络世界，而是由时间串起的无数因果网络而构成的三维因果系统世界。
5. 不要误以为统计概率是理科生才需要的东西……但凡想理解大量且复杂的事实，且需要深入分析，都需要扎实的统计概率基础。（详见 ch08 2.4 贝叶斯定理）
6. 设计论者不能接受意外和不可想象，他们本质上需要一个确定的未来——当然这从来都只能是一厢情愿。发展论者笃行的是发展的存在与发展的力量，而不是哪个确定的发展结果——未来是不确定的，也应该是不确定的。
7. 从定义、分类、比较、因果这四个极为简单的要素构成的思考框架开始，不断迭代……逐步形成所谓的命运。

## 看厚读书法（如何把薄书学透）
- 薄册子要"反复看""多看几遍""看厚"——用过往著作/课程/生活经历去填充。
- "你还要把它讲很多遍"——讲给家人听，把它变成你的讲义。
- 检验真学没学到：脑中三张表是否真的发生了变化（见上"判断标准"）。

## 框架的应用（投资 / 学习 / 人生）
- **与财富**：李笑来称其财富（如《托福核心词汇21天突破》长期版税、《通往财富自由之路》稿酬、GAFATA/ANATM 及港交所 ETF 投资）均源自这套清晰简单的思考框架；关键是"定义不同 → 理解不同 → 分类比较不同 → 决策不同"。
- **与学习/自学**："思考其实是每个人受教育的素质基础，也是每个人自学的基础"；学校不教思考，故需自修。
- **与人生**：命运是四要素经时间迭代的产物；"用正确的方式去做正确的事情"（出自《把时间当做朋友》）——事错则越高效越倒霉，事对则效率稍低无妨。

## 统计概率与贝叶斯（指向 ch08 2.4）
- 贝叶斯定理是"面向未来"且可递归迭代的因果推理工具，是人类首个预测未来的算法（The Master Algorithm）；传统统计概率"面向过去"且一次性。
- 对"三维因果系统世界"中的"未知/未来"，贝叶斯的迭代更新（不断提高假说正确概率）正是三张表 CRUD 的数学化体现。
