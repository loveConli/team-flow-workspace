# ch02 — 1.1 定义

## 核心定义
- **定义的核心是一个等号**：等号左边是概念，右边是描述。**概念 = 描述**。
- 学科由"相互关联的概念"构成，每个概念都有精确且完整的定义（如物理：加速度 = 速度的变化量 / 发生这一变化所用时间）。
- 人脑中有一张"概念表"；**学习 = 新建/更新/删除概念**，实践 = 读取（调用）概念。

## 关键原则
- **定义的要求：有必要且无歧义**（即"准确"的另一种说法）。
  - 等号左边的概念是**必要**的 → 没必要的就删掉。
  - 等号右边的描述是**准确**的 → 即**毫无歧义**，有歧义就反复更新直至毫无歧义。
  - 但凡有一条做不到，就需要更新甚至删除该概念。

## 操作步骤（定义四步）
1. 写出等号：**概念 = 描述**。
2. 检查左边概念：是否必要？不必要则删。
3. 检查右边描述：是否毫无歧义？有歧义则反复更新。
4. 多面事物可从另一角度重新定义（如"时间就是金钱""时间是一种生产资料"）。
5. 动态维护概念表：新建/读取/更新/删除（类比数据库 **CRUD**: Create/Read/Update/Delete）。

## 反模式
- 保留不必要的概念（违反"必要"）。
- 描述有歧义却不更新（违反"无歧义"）。
- 概念不满足"必要且无歧义"却不更新/删除。
- 视角单一、不重新定义 → 理解僵化。

## 具象例子
- **物理概念链**：加速度=速度变化量/时间；速度=位移/时间；位移=初位置到末位置的有向线段（矢量）；矢量=既有大小又有方向的物理量。
- **燃素（概念删除）**：1650 年后百余年人们认为可燃物含"燃素"，后被拉瓦锡删除，标志近代化学崛起。
- **上火 vs 炎症（概念更新）**：古人归为"火"，现代医学更新为"炎症"（删"火"、建"炎症"）。
- **时间的多角度定义**：物理上为标量尺度；生活中"时间就是金钱""时间是一种生产资料"。

## 与其他要素的关系
- 定义是其余所有要素的基石：**想要分类合理，就要先定义清楚**。
- 全书顺序：定义 → 分类 → 比较 → 因果；决策为其组合，流程落地需"必要且毫无歧义的定义"为前提。
- 决策差异常源于定义差异（见 ch06 特斯拉案例）。
