# ch03 — 1.2 分类

## 核心定义
- "有些概念是**集合概念**"，即由多个确定的元素或概念构成的整体（如"灵长类动物"含猴、猿、人类）。
- 对集合概念所包含的各概念，为分析和决策而做的工作，就是**分类**。

## 关键原则
- **合理且完整是良好分类的最基本要求，就是这么简单。**
  - **合理** = 各个子类别之间**互不重合**。
  - **完整** = 所有分类加起来应该**等于全部**。
- 即《金字塔原理》所说的 **MECE（相互独立、完全穷尽）**；原书未用"MECE"一词，而是以"合理且完整 / 不重合且完整"表达同一思想。

## 操作步骤（分类检查）
1. 确认对象是否为**集合概念**。
2. 将其包含的概念划分类别。
3. 检查类别间是否**互不重合**（合理）。
4. 检查所有类别加起来是否**等于全部**（完整）。
5. 应用：生活中"全面思考，归根结底就是分类得足够合理、足够完整"。

## 反模式
- **重合（不合理）**：如"生产四要素"中"资本"能买到土地/劳动力/企业家才能，却与其他三类并列 → 不互斥。
- **不完整**：剔除资本后仅剩土地/劳动力/企业家才能，无法构成完整生产要素。
- **胡搞瞎搞（乱塞）**：把本不属于该集合的概念硬塞进来。经典案例：李森科捏造"获得性遗传"，包装成"米丘林生物学"，硬塞进"科学"这一集合概念。
- **错误剔除**：把明明属于某集合的概念剔除出去（如认为逻辑训练不该属于基础教育）。

## 具象例子
- **生产四要素（不良分类）**：土地、劳动力、企业家才能、资本 —— 资本与其余重合、整体不完整。
- **灵长类动物（集合概念）**：含猴、猿、人类。
- **李森科 / 米丘林生物学（最糟分类）**：硬塞入"科学"。
- **图书馆 / AI**：作者母亲为医学院图书馆馆长，图书馆核心是情报学、情报学核心是分类；AI 训练前需"清洗数据、打标签"，基础核心也是分类。
- **高考志愿 / 问题归因**：原因分析如何分类、判断标准如何分类、事物需考虑哪些方面——本质都是分类。

## 与其他要素的关系
- 顺序：**想要分类合理，就要先定义清楚**；**比较之前得先做到分类合理**。
- 分类确定关系：后续"关系"章中，分类之后确定从属/同属/相交或不相交关系（见 ch08）。
