# ch04 — 1.3 比较

## 核心定义
- 比较的标题式定义：**比较 / 同一范畴 / 同一属性**。
- "两个事物之所以可以相互比较，原因有两点：一是它们属于**同一范畴**；二是它们拥有**相同的属性**。"（如苹果和橘子都属于水果，会比较哪个更好吃。）

## 关键原则
- **同一范畴、同一属性**是可比前提。
- **判断依据：主观 / 客观**：
  - 主观的判断依据不是没用，只是它本身不可争辩，用它做出的判断也不可争辩。
  - 判断依据**最好是客观的**，这样它就可以被量化、被精确比较。
- 多客观依据并存时，须**按重要性排列、分别赋权重、打分、计算总分**。

## 操作步骤（加权比较）
1. 确认比较对象"属于同一范畴"且"拥有相同属性"。
2. 明确**判断依据**，优先采用**客观**（可量化）依据。
3. 多依据时：排列重要性 → 分配权重 → 逐项打分 → 总分 = Σ(分数 × 权重)。
   - 实例（高考选校）：四依据 = 学校排名(40%)、地理位置(30%)、专业设置(20%)、学费(10%)，对 A/B/C 三校打分，A=8.2、B=7.9、C=7.4。

## 反模式
- **胡乱比较，不在意主观/客观**：生活中常见，"主观的判断依据……不可争辩"，纠结或争辩无意义（如"两件衣服哪件更好看"）。
- **跨范畴 / 不同属性比较**：违背"同一范畴、同一属性"即不可比。
- **判断依据匮乏**："'判断依据'只能靠不断积累，谁都没办法从一开始就获得或掌握所有判断依据"——需长期积累，非一次解决。

## 具象例子
- **水果比较**：苹果 vs 橘子（同一范畴"水果"、同一属性"好吃"）。
- **衣服好看（主观反例）**：判断依据主观，纠结/争辩无意义。
- **身高比较（客观正例）**：身高可测量、差值可计算。
- **高考志愿（多权重实操）**：见上，A/B/C 三校加权打分。
- **电影评价（依据积累困境）**：类型/题材、导演演员、票房评分奖项、剧情人物、社会文化价值……日常仅凭"爽不爽"主观打分，一旦要求客观便工作量非凡。

## 与其他要素的关系
- 顺序：**比较之前得先做到分类合理**，才能基于同一范畴、同一属性比较；**想要分类合理，就要先定义清楚**。
- 比较确定关系："比较 → 约等于 / 大于（小于是镜像）/ 等于忽略 / 不等于二选一"；"约等于对应一种思考模式，叫**类比**——它非常重要"（见 ch09）。
- "所谓的智能，核心只不过是判断；而判断的核心，无非是恰当的比较和合理的分类，前提是必要且毫无歧义的定义。"
