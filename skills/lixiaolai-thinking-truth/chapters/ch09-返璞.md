# ch09 — 3 返璞：类比 / 发展 / 简单 / 升级

> 返璞章回归本质。本章依据知识库「LT的知识库」《思考的真相》(李笑来).pdf 完整正文提取。其中 3.1/3.2/3.4 充分；3.3 简单在可用文本片段中缺失（见该节说明）。

## 3.1 类比
- **原话**："约等于也是事物与事物之间的一种关系，类比就是个极为神奇的思考工具，常常被用来跨越'已知'和'未知'之间那原本不可逾越的鸿沟。为了理解陌生的 X，我们找来格外熟悉的 A，在 X 和 A 之间画一个约等号，$X \approx A$。而后，借助 A 的种种与 X 类似的属性，去理解 X。"
- **例子（鸡蛋 ↔ 地球）**："我们从小就是靠类比学习的。小时候，老师为了帮我们理解地球的结构，会提醒我们先想想鸡蛋。蛋的结构你们早就知道，蛋黄、蛋清、蛋壳，对吧？地球也一样，地核、地幔、地壳。借助熟悉的鸡蛋，我们理解了原本陌生的地球结构。这就是类比——用已知理解未知。"
- **方法步骤**：1) 锁定陌生对象 X；2) 找格外熟悉的 A；3) 画约等号 $X \approx A$；4) 借 A 的类似属性理解 X。
- **与其他要素关系**：来自 1.3 比较中"约等于"这一分支（"约等于对应一种思考模式，叫作类比"）；是 2.3「用已知探索未知/预测未来」的具体工具。

## 3.2 发展
- **核心例子（NetLogo 虚拟蚂蚁 Vants 模型）**：仅一条极简确定性规则——"左转，前行一步"（需取消"World wraps"观察边界内真实演化）。发展分三阶段：
  1. **简单阶段**：最初几百步，形成非常简单的对称图形。
  2. **混沌阶段**：几百步后，形成毫无规则的随机图形。
  3. **秩序阶段**：约一万步后，"秩序"突然涌现——蚂蚁足迹显现一个由 104 步构成的图形（被戏称"高速公路"），永不停歇。
- **含义**：复杂秩序可从**极简单规则经时间"发展"涌现**，无需外在设计者。呼应"发展论者"立场（见下）。
- **发展论者 vs 设计论者**（来自读者"7句话"第6句，非 PDF 正文逐字）：设计论者"需要一个确定的未来——一厢情愿"；发展论者"笃行发展的存在与发展的力量，而非某个确定的发展结果——未来是不确定的，也应该是不确定的"。
- **覆盖范围说明**：Vants 三阶段来自 PDF 正文；"发展论者/设计论者"精确表述仅见于读者笔记/直播稿，PDF 正文该对比未出现。

## 3.4 升级（三张表 = 大脑操作系统）
- **原话**："无论是有意还是无意，我们的脑子里都有三张表：概念表、关系表、流程表……这三张表就构成了我们的操作系统……本质上来看都是对这三张表执行 CRUD 操作——新建、读取、更新和删除。而所谓升级，本质上不过是在不断 CRUD 而已。……发展是什么意思？不过就是这三张表在不断迭代而已。"
- **三表 ↔ 认知/判断/行动**：概念表 → 认知；关系表 → 判断；流程表 → 行动。"三张表的形成是有先后顺序的。首先得概念表梳理得足够好，关系表才可能足够清楚，而后流程表才可能保持最优。从动作上来看，先有认知，后有判断，然后才是行动。"
- **电脑 vs 人脑对照**：电脑配置未改 + 软件升级 → 完成更多任务；人脑身体未变 + 知识积累（三表 CRUD）→ 完成更多任务。"有太多的人不学习，相当于不升级自己的操作系统；不做笔记，相当于从不清理自己的文件系统；不在意选择，相当于安装的全都是乱七八糟的软件；不在意效率，相当于几乎没有有用的生产工具。"
- **判断标准（极重要）**："真正有意义的学习（无论好书、好课还是好的讨论），一切有意义的思考和实践……都会引发这三张表的变化、积累或者更新。反过来，如果花钱买了书买了课……这三张表竟然没有发生任何变化，那其实等于没学、没思考、没实践——钱白花、时间白费。"
- **命运公式**："这三张表刚开始几乎空空如也，从定义、分类、比较、因果这四个极为简单的要素构成的思考框架开始，不断迭代。随着时间的推移，概念表、关系表、流程表开始逐步积累……经过长时间的反复，形成各种认知、判断、行动，最终通过时间这个发展的唯一路径，逐步形成所谓的命运。起初的时候，谁能想象？"
- **被点名的词**："一维因果世界""二维因果网络世界""三维因果系统世界"——李笑来称为"中文世界里第一次出现的词"（回扣 2.2）。

## 与其他章的关系
- 类比承接"比较→约等于"；发展承接"因果/未知"的不确定性 + 维度"时间串起系统"；升级收束全书于三张表/CRUD，把 2.4 贝叶斯的"递归迭代"落到日常思维操作层。
