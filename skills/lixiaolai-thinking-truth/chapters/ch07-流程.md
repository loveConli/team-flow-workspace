# ch07 — 1.6 流程

## 核心定义
- **描述—动作对应表**：
  | 描述 | 动作 |
  |------|------|
  | 什么（What：什么人/地方/时间/事） | 定义 |
  | 为何（Why） | 决策 |
  | 如何（How） | 流程 |
- "**做事的本质，做什么都一样，无非是对流程的规划和管理；把事做好或提高效率，无非就是对流程的优化而已，无他。**"
- **流程三模块**（结构化程序定理）：天下所有流程由三种模块组成——
  1. **顺序**（按顺序执行）
  2. **循环**（重复执行）
  3. **判断与分支**（不同情况执行不同步骤）

## 关键原则
- **时间客观不可压缩/跨越**：小事或一步完成；大事需拆分成小事并统筹（先干/后干/同时干/何种情况下干）。
- **流程可拆分管理**："生活中的一切任务，到最后都可以画个流程图出来，进而管理或优化……无论多大的事情，都可以无限拆分直至化为一个个小模块。"
- **统筹核心**："串联：哪些步骤可不分先后、哪些必须有先后；并联：哪些可同时进行。**节省时间的核心在于能并联的都并联。**"

## 操作步骤（流程设计与统筹）
1. **三步描述框架**：What→定义，Why→决策，How→流程。
2. **流程三模块**：顺序、循环、判断与分支。
3. **设计方法——拆分与统筹**（华罗庚泡茶例）：拆任务为若干步骤 → 算出每步时间 → 研究步骤关系（串联/并联）。
   - 例：洗开水壶1分 → 烧开水15分（**同时**洗茶壶1分、洗茶杯2分、拿茶叶1分）→ 泡茶，共 16 分。
4. **流程图绘制**：背课文流程图示例——熟悉课文（循环朗读十遍）→ 拆解逻辑关系（判断分支）→ 背诵与检查。

## 反模式
- **漏掉步骤**：顺序流程"漏掉某个步骤……不仅常见，且可能造成灾难性后果"——小事如出门忘带钥匙/钱包/手机；大事如开车前漏检车胎酿车祸。
- **缺乏逻辑拆解**：背课文只熟读顺下来，缺"拆解逻辑关系"步骤，易卡壳。
- **毫无章法**："大多数人在厨房里忙得焦头烂额……到了工作岗位也一样，大多数人做事毫无章法。"
- **机械无判断**：流程若只由固定顺序步骤构成就"非常机械……只不过机械自动化而已"；加入"判断"才"非常智能"。

## 具象例子
- **下象棋**：同规则博弈有输赢，"先干什么后干什么"决定胜负（策略=顺序）。
- **背课文**：熟悉课文（循环）→ 拆解逻辑关系（判断）→ 背诵检查（分支），附流程图。
- **泡茶**：华罗庚例，串联+并联省时至 16 分。
- **出门/开车检查**：漏步骤反面；开车前检轮胎为小流程正向。
- **创业/管理公司/家庭教育**：皆是可流程管理优化的大任务。

## 与其他要素的关系
- **与定义/决策并列**：What→定义，Why→决策，How→流程。
- **流程 = 规划与管理**：把前序思考成果（清晰定义的概念、分类比较的选项、因果决策的依据）在时间与步骤上串起，形成可优化操作链。
- **流程中的智能**：因果四问流程图含"判断与分支"；"所谓的智能，核心只不过是判断；而判断的核心，无非是恰当的比较和合理的分类，前提是必要且毫无歧义的定义。"
