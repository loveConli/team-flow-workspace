# Glossary — 《思考的真相》关键术语

按拼音/字母排序。`**术语** — 定义（出处章）`

- **CRUD** — 新建/读取/更新/删除四种概念操作，对应学习的本质：学习=新建/更新/删除概念，实践=读取概念 (Ch 02, 10)
- **MECE** — 相互独立、完全穷尽（Mutually Exclusive, Collectively Exhaustive）；与书中"合理且完整"同义。原书未使用"MECE"一词 (Ch 03)
- **必要且无歧义** — 良好定义的标准：等号左边的概念必要（没必要则删），右边的描述毫无歧义（有歧义则反复更新） (Ch 02)
- **概念=描述** — 定义的核心等式：等号左边是概念，右边是描述 (Ch 02)
- **概念表** — 人脑中存储概念的集合，由定义维护；三张表之一 (Ch 02, 10)
- **关系表** — 记录概念间关系（从属/同属/相交、与或非、比较的大于/约等于/不等于、因果/相关/无关）的表；三张表之一，对应"判断" (Ch 08, 09, 10)
- **流程表** — 记录做事步骤与顺序/循环/判断分支的表；三张表之一，对应"行动" (Ch 07, 09, 10)
- **合理且完整** — 良好分类标准：子类互不重合（合理）+ 子类加起来等于全部（完整） (Ch 03)
- **不重合且完整** — "合理且完整"的另一种表述，即 MECE (Ch 03)
- **比较 / 同一范畴同一属性** — 两事物可比较的前提：属于同一范畴、拥有相同属性 (Ch 04)
- **判断依据 主观/客观** — 比较的依据；客观可量化、可赋权重，优于主观 (Ch 04)
- **加权打分** — 多客观依据时按重要性赋权重、逐项打分、算总分（Σ分数×权重） (Ch 04)
- **因果 / 时间先后≠因果** — 因果第一原则：原因在前结果在后，但时序不保证因果 (Ch 05)
- **相关非因果** — 两事物同因于第三方而非互为因果（如冰激凌销量↑与溺水↑同因于天热） (Ch 05, 08)
- **因果四问模板** — A真因B？唯一因？还有哪些因？最重要因？ (Ch 05)
- **四要素组合嵌套** — 每个决策都是定义+分类+比较+因果的组合与多轮嵌套 (Ch 06)
- **顺序/循环/判断与分支** — 构成一切流程的三种基本模块 (Ch 07)
- **串联/并联统筹** — 流程优化核心：弄清步骤先后，能并联的都并联以省时 (Ch 07)
- **从属/与或非/并列递进转折** — 关系的基本类型 (Ch 08)
- **三维因果系统世界** — 世界由时间串起的无数因果网络构成 (Ch 08)
- **未知** — 面对复杂因果网络承认不可全知，保持谦逊、倚重证据与概率 (Ch 08)
- **类比** — 由"比较"中的"约等于"发展出的高级思考方式（启发而非证明） (Ch 09, 04)
- **设计论者 / 发展论者** — 两类未来观：前者要确定的未来（一厢情愿），后者笃信发展的力量、接受不确定 (Ch 09)
- **简单 / 升级** — 返璞归真研究简单要素；升级=让三张表更准更全更活 (Ch 09)
- **三张表 / 大脑操作系统** — 概念表+关系表+流程表，构成人脑思考的操作系统 (Ch 10, 01)
- **看厚读书法** — 薄书反复读、用经历填充、讲给别人听，使三张表真正变化 (Ch 10)
- **统计概率基础** — 理解大量复杂事实、做深入分析与决策的必要工具；贝叶斯定理是其面向未来的核心 (Ch 08, 10)
- **与/或/非（AND/OR/NOT）** — 相交集合概念间的逻辑运算，配维恩图使用（如"既喜欢苹果又喜欢香蕉"=与） (Ch 08)
- **贝叶斯定理** — $P(A|B)=\frac{P(A)\times P(B|A)}{P(B)}$；面向未来、可递归迭代的因果推理算法，被誉为人工智能"终极算法(The Master Algorithm)"；传统统计概率面向过去且一次性 (Ch 08)
- **维度 / 三维因果系统世界** — 由"一维因果(一对一、时间只是干扰)→二维因果网络(互为因果、时间必要)→三维因果系统(时间串起无数因果网络)"逐级升维理解世界 (Ch 08)
- **未知 / 预测未来** — 思考核心目标=探索未知（很大一部分是预测未来）；最大未知来自未来；巫术/宗教/科学的主要场景都是预测未来 (Ch 08)
- **相关非因果** — 两事物同因于第三方而非互为因果（如冰激凌销量↑与溺水↑同因于天热）；共变≠因果 (Ch 08, 05)
- **类比** — 由"比较"中的"约等于"发展出的工具：对陌生 X 与熟悉 A 画约等号 $X\approx A$，用已知理解未知（鸡蛋↔地球） (Ch 09, 04)
- **发展（三阶段）** — NetLogo 虚拟蚂蚁模型：极简规则经时间涌现"简单→混沌→秩序"三阶段，秩序可自发展而来 (Ch 09)
- **升级** — 三张表持续执行 CRUD 即升级；判断标准=任何学习/思考/实践若未引起三表变化则等于没学 (Ch 09, 10)
